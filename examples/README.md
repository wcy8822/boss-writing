三个例子，覆盖最高频的三类失败。每个例子都是一段完整材料，不是单句——
单句对照看不出差别，段落才能。

| 例子 | 治什么 | 对应规则 |
|---|---|---|
| [01 抽象价值 → 任务前后变化](01-抽象价值-改成-任务前后.md) | 句子没错，但听完不知道自己少做了什么 | §P0·八 §一.1 §三 |
| [02 归责写法 → 对事不对人](02-归责写法-改成-对事不对人.md) | 逻辑正确，但让听的人坐不住 | §P0·五 |
| [03 罗列工作 → 数字带解读](03-罗列工作-改成-数字带解读.md) | 汇报了劳动过程，没有汇报业务变化 | §一.3 §一.8 §二 |

例子里的产品名、数字与业务场景均为虚构。
