# 战略汇报材料视觉标准（v6.2 · 落地版）

> 本文 = 原始标准 `原始标准-v6.2.md` + 两个模板的**实测实现** + 评审追加的铁律。
> **实现与文字描述不一致处，以实测为准**（示例是能跑且被认可的），不一致点在文末列明。
>
> 适用：所有对内战略会、季度规划类 HTML 汇报材料。

## ⛔ 第一铁律：不用黑框压顶

**首屏 hero、结尾 ask 一律不用纯黑满版底（`--ink-900 #13140f`）。**

评审反馈的原话是「这种大的黑框压顶的视觉不要再用了」。黑色满版是压迫感的来源。改用与正文同调的浅色底，文字转暖调深色，品牌橙只留给强调处。

⚠️ **改造既有材料时必须查最终生效值**：这套 CSS 是「旧规则 + 追加覆盖块」的形态，同名选择器有 4–5 条，
`grep '.hero'` 看到的第一条永远是旧的纯黑。**必须取最后一条**，或直接在浏览器里读 computed style。
（踩过：v6.0 文案已换新、视觉仍是黑 hero，因为覆盖块没跟上。）

## 两个标准

同一份文案，两套配色。**结构、组件、字号完全一致，只有底色不同**（示例已实测：两版正文 md5 相同）。

| | **暖色版**（暖阳） | **清新版**（清新报告） |
|---|---|---|
| 模板 | `template-warm.html` | `template-fresh.html` |
| Hero 底 | `#FFF9F2` 暖米白 | `#FFFFFF` 纯白 |
| ASK 底 | `#FFF9F2` | `#F5FAF4` 极浅绿 |
| 辅助渐变 | `linear-gradient(175deg,#FFF9F2,#FFEED8,#FFE0C0)` | `linear-gradient(175deg,#F5FAF4,#E8F3E5,#DFF0DB)` |
| 适用 | 强调**共创 / 温度**：季度规划、复盘 | 强调**协作 / 生长**：项目型汇报 |

**怎么选**：材料结尾是「邀请大家一起来」→ 暖色；是「阶段性交付说明」→ 清新。
拿不准选暖色（季度规划大会默认）。

## 八条标准（含实测值）

**1. 不用纯黑深色板块** —— 见上方第一铁律。

**2. 暖调墨色，不用纯黑文字**
```css
--fg-1:#2A2320;   /* 正文标题 */
--fg-2:#6D635A;   /* 正文 */
--fg-3:#9A8C7E;   /* 说明 / 元信息 */
```
⚠️ 注意这三个值**覆盖**了基础 CSS 里的 `--fg-1:#0a0a0a` 等，覆盖块必须放在基础规则之后。

**3. 章节序号用圆形徽标，不用巨型数字**
不用 96px 超大数字（压迫、占位重）。实测值 **44px 圆形**（原文写 56px，以实测为准）：
```
[①] 眉标
    标题
    引导语
```

**4. 提示 / 高亮框：无侧边框，柔色通栏**
避开「圆角容器 + 左侧色条」的套路写法。改 `background:var(--yellow-50); border:none; border-radius:14px`。

**5. 卡片悬浮反馈**
`transform:translateY(-2px)` + 柔和阴影，不用生硬的边框变化。

**6. 顶部阅读进度条**（3px 固定条，随滚动填充，品牌橙）
⚠️ **两个模板都没实现**，是遗漏不是否决，建议补上。
实现时注意——**进度条依赖 JS 计算滚动比例，属于「锦上添花」层**，
JS 挂了只是没有进度条，不能影响任何内容可见性或切换功能（见 `../SKILL.md` 交互铁律）。

**7. 留白收紧节奏**

| 位置 | 用 | 不用 |
|---|---|---|
| 大 section 纵向 padding | 56–64px | 96px |
| hero / ask 纵向 padding | 40–56px | 80–96px |
| 章节头到正文 | 32px | 48px |
| 卡片内部 padding | 24px | 32px |

**8. 品牌色锁死，不跟着参考材料走**
模板里的 `--orange-500` 是占位色，**换成你自己的品牌主色**（改 CSS 顶部 `--orange-*` 一组即可全局生效）。
视觉手法可以借鉴别家材料，品牌色不借用。
⛔ 深色实底上的文字一律用白色（`--on-orange #ffffff`）——中文 web 视觉惯例，即使深色文字对比度更高也不用。

## 怎么起步

```bash
# 复制模板做起点（暖色版）
cp visual/template-warm.html <目标>.html
# 然后只换 <body> 内容，CSS 一行不动（品牌色除外）
```

模板正文是虚构示例，整段替换即可。

改造既有材料（已有旧版 HTML）：保留 head/CSS，在 `</style>` 前**追加覆盖块**，
再整体替换 body。覆盖块要显式写 `.hero`/`.ask` 的新底色，否则旧的纯黑会一直生效。
