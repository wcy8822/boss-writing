# 战略汇报材料视觉标准（v6.2）

来源：多轮季度汇报材料（暖阳版 / 清新版 / 报告风格版）的迭代沉淀。
适用范围：所有对内战略会、季度规划类 HTML 汇报材料。

## 使用时机
写新的汇报材料，或审别人写好的材料时，按下面 8 条逐项检查。两份参考实现（暖色 / 清新）在本包内，可直接复制做起点。

## 标准

**1. 不用纯黑深色板块**
首页 hero、结尾 ask/CTA 区不用纯黑（`--ink-900`）满版底色——那是压迫感的来源。改用与正文一致的暖色渐变（如 `linear-gradient(175deg, #FFF9F2, #FFEED8, #FFE0C0)`），文字转为暖调深色，品牌色只用在强调处。

**2. 暖调墨色，不用纯黑文字**
```
--fg-1: #2A2320   正文标题
--fg-2: #6D635A   正文
--fg-3: #9A8C7E   说明 / 元信息
```

**3. 章节序号用圆形徽标，不用巨型数字**
不用 96px 超大数字（视觉压迫、占位过重）。改用 56px 圆形徽标（浅色底、品牌字色），紧邻眉标 + 标题横排：
```
[①] 眉标
    标题
    引导语
```

**4. 提示/高亮框：无侧边框，柔色通栏**
避免"圆角容器 + 左侧色条"套路化写法。改无边框、纯柔色背景的通栏圆角框：`background:var(--yellow-50); border:none; border-radius:14px`。

**5. 卡片悬浮反馈**
关键卡片加悬浮：`transform: translateY(-2px)` + 柔和阴影，不用生硬的边框变化。

**6. 顶部阅读进度条**
长页面加一条 3px 固定进度条，随滚动填充，用品牌色。低打扰、给现场一个"还有多少"的预期。

**7. 留白收紧节奏**
- 大 section 纵向 padding：56–64px，不用 96px
- hero/ask 纵向 padding：40–56px，不用 80–96px
- 章节头到正文间距：32px，不用 48px
- 卡片内部 padding：24px，不用 32px

**8. 品牌色不换**
主品牌强调色维持你所在项目的既定色值，不借用参考材料里的其它色值——视觉手法可以借鉴，品牌色不换。

## 两个方向怎么选
- **暖色版**：主基调走暖橙渐变，适合强调"共创/温度"的季度规划、复盘类汇报。
- **清新版**：hero 走白底+绿意点缀，ask 走草绿渐变，适合强调"协作/生长"的项目型汇报。
两版共用第 1–7 条标准，只有底色和辅助色不同（第 8 条已保证品牌主色不漂移）。
